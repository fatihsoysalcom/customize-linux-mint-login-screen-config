# Customize Linux Mint Login Screen Config

This script demonstrates how to programmatically modify a mock configuration file for the Linux Mint LightDM greeter (slick-greeter). It shows how to change settings like the background image path and theme, simulating the process of customizing the login screen. In a real Linux Mint environment, similar commands would be applied to `/etc/lightdm/slick-greeter.conf` and would require `sudo` privileges.

## Language

`bash`

## How to Run

Save the script as `customize_login_screen.sh`. Make it executable with `chmod +x customize_login_screen.sh`. Run it using `./customize_login_screen.sh`.
